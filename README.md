# milledesk
Created for recruitment process task

How to start locally
Backend:
1. Open dotnet/Milledesk.Backend.sln
2. Make sure that startup project is Milledesk.Api
3. Start from visual studio by clicking Debug -> Start Debugging

Frontend:
1. Go to react folder
2. Open anhy terminal and type "npm install"
3. after install type "npm run dev"

backend is running on port 7259 and frontend on 5173
